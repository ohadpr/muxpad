The working indicator — nine ways to say "thinking"

All drop-in: they sit in the same flex row as today's dots, inherit var(--chat-faint), and fit the 26×16px the three bouncing dots already occupy, so the label beside them never moves.

Two constraints that are doing real work here. 208 panes exist on this machine, and several can be working at once, so each one is marked by what it costs the compositor — transform + opacity animations run on the GPU and never touch layout; a filter does not. And every one of them stops under prefers-reduced-motion.

01Orbit

Two dots on one ring, half a turn apart, each scaling and fading as it passes behind the other. Two flat circles read as depth — the oldest trick in the book and still the best one. Unmistakably circling a problem.

transform + opacity

02Caret

The text cursor that is about to appear anyway, breathing: it squashes flat and springs back. It is the only option that says a sentence is coming rather than a machine is busy — and it morphs into the real streaming cursor for free.

transform + opacity
Bash · 14s

03Equaliser

Four bars on a phase-shifted sine, scaled from the baseline. Reads as a live signal rather than a timer — something is coming through, not merely elapsing.

transform + opacity
Bash · 14s

04Goo

Two metaballs that merge into one pill and tear apart again, via an SVG blur + contrast matrix. The showiest thing here by a distance. Slow it down to see the surface tension.

05Trace

A marching dash running the perimeter of muxpad's own rounded square, over a faint ghost of the full outline. The most vector of the set, and the only one carrying the product's shape instead of a generic primitive.

stroke-dashoffset — paint, not layout
Bash · 14s

06Comet

A conic gradient masked into a 2.5px ring: a tapered arc chasing its own tail. One element, no SVG, no children. The safest "it is clearly working" of the nine, and the most familiar.

transform only
Bash · 14s

07Triad

The same three dots you have now, welded into a rigid triangle that rotates while each vertex pulses out of phase. Minimal change from today, completely different character.

transform + opacity
Bash · 14s

08Wave

Four dots on a travelling sine, scaling as they rise. Today's idea taken seriously — a wave moving through the dots rather than three of them taking turns.

transform + opacity
Bash · 14s

09Scanner

Three dots sit still and a hairline sweeps across, firing each as it passes, then snaps back. Mechanical and deliberate — it reads as reading, which is usually what is actually happening.

transform + opacity

If you want one: 02 Caret. It is the only one that is about this product rather than about waiting — the cursor is already what appears the instant the first token lands, so the indicator and the stream become one object that morphs instead of two that swap. It is also the smallest and the cheapest.

If you want crazy cool: 01 Orbit. Two circles and a scale keyframe buy a genuine sense of depth, it is unlike what any other chat app does, and it costs the compositor nothing. 04 Goo is more spectacular and I would not ship it — an SVG filter repainting every frame, in a pane that can have siblings also working, is a real cost for an element 26px wide.

Whichever: keep the aria-label that is there now, and keep the prefers-reduced-motion branch — under it every one of these should hold a single static frame rather than vanish, so the row does not change height.
